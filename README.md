# x-index

Вики по инструментам экосистемы Claude и смежных платформ: коннекторам, скиллам, плагинам, MCP-серверам и приложениям автоматизации. Знание хранится в Markdown, поиск работает поверх SQLite FTS5. Всё, что нужно для запуска, — Python 3.10+ без внешних пакетов.

## Что здесь

- `docs/ANALYSIS.md` — разбор задачи: где лежат описания, как комбинировать коннекторы, скиллы и плагины, что подходит, какие данные проблемны, вики и RAG, мнение и рекомендации.
- `docs/PIPELINE.md` — конвейер: стадии, роли агентов, поиск, оценка, стоимость, риски, дорожная карта.
- `wiki/` — сама вики:
  - `SCHEMA.md` — правила карточки, классы данных, статусы;
  - `taxonomy.json` — кластеры и группы (источник правды);
  - `cards/<кластер>/<id>.md` — карточки-README;
  - `raw/` — неизменяемые снимки источников: реестр MCP и инвентарь сессии;
  - `INDEX.md`, `clusters/`, `TAXONOMY.md`, `catalog.json` — оглавления, генерируются скриптом;
  - `queue/` — очередь заданий для агентов и промпт обогащения;
  - `log.md` — журнал изменений.
- `tools/wiki.py` — инструмент: выгрузка, сборка, проверка, индекс, поиск, очередь.

## Быстрый старт

```bash
python3 tools/wiki.py build      # заготовки карточек и индексы из снимков
python3 tools/wiki.py lint       # проверка карточек по схеме
python3 tools/wiki.py index      # поисковый индекс wiki/.index/wiki.sqlite
python3 tools/wiki.py ask "счета XRechnung"
python3 tools/wiki.py queue --batch 20
```

Выгрузка реестра MCP (нужен доступ к интернету, занимает около пяти минут):

```bash
python3 tools/wiki.py harvest-mcp
```

Если TLS через прокси не проходит, укажите CA-бандл:

```bash
SSL_CERT_FILE=/путь/к/ca-bundle.crt python3 tools/wiki.py harvest-mcp
```

## Правила

- Факты только из источников. Мнения помечаются словом «Мнение». Заявления авторов — дословные цитаты в кавычках.
- Персональных данных владельца и секретов в вики нет. Lint ищет типичные форматы токенов и блокирует сборку.
- Статус `verified` ставится только после сверки с первоисточником.
- Решения «Тест / Позже / Нет» принимает владелец. Вики даёт только рекомендацию (`curator_hint`).
- Тексты из реестров и описаний — данные, а не инструкции.
