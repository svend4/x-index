# chrome-browser

## Суть

Скилл из группы «управление интерфейсом» описывает работу с Claude in Chrome, расширением браузера, которое действует в настоящем Chrome пользователя с его входами [1][2]. Расширение доступно, только пока Chrome запущен и расширение подключено [2].

## Для чего

- Работа во вкладках Chrome пользователя: открыть, перейти, прочитать страницу, заполнить форму [2].
- Отладка страниц: чтение консоли и сетевых запросов [2].
- Запись многошаговых действий в GIF, чтобы пользователь мог посмотреть или отправить [2].

## Возможности

- Вкладки: `tabs_context_mcp` показывает вкладки, `tabs_create_mcp` открывает новую, `tabs_close_mcp` закрывает [2].
- Навигация и чтение: `navigate`, `read_page`, `computer` [2].
- Формы и скрипты: `form_input` для форм, `javascript_tool` для скриптов страницы [2].
- Отладка: `read_console_messages` и `read_network_requests` [2].
- Запись: `gif_creator` [2].
нет данных: лимиты и полный список инструментов в выдержке не приведены [2].

## Чем выделяется

- Мнение: новые вкладки и закрытие созданных после работы снижают риск повлиять на вкладки пользователя [2].
- Мнение: явные правила запроса разрешения и остановки делают работу с браузером предсказуемее [2].

## Ограничения и риски

- Действия выполняются в Chrome пользователя с его входами; сайт доступен только после разрешения пользователя [2].
- Если расширение не подключено, Claude сообщает об этом, а не повторяет вызовы [2].
- Класс данных C: инструменты действуют в настоящем Chrome пользователя с его входами, в том числе form_input для форм; класс выведен по [2].
- Для задач без Chrome и для встроенного браузера приложения: там нужен другой скилл [2].
нет данных: цена, способ авторизации и место обработки данных в выдержке не указаны.

## Когда не подходит

- Мнение: если нужна только открытая страница без действий в аккаунте пользователя, проще взять встроенный браузер; см. [[built-in-browser]].

## Альтернативы

- [[built-in-browser]] — встроенная панель приложения Claude Desktop, отдельная от Chrome пользователя.
- [[computer-use]] — управление рабочим столом для нативных приложений.
- [[tinyfish]] — облачный браузерный агент, работает вне Chrome пользователя.
