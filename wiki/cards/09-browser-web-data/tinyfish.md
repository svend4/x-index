# TinyFish (коннектор)

## Суть
TinyFish — облачный браузерный агент. Он открывает сайты, извлекает страницы, ищет в вебе, мониторит изменения и собирает наборы данных. По описанию каталога он может входить в личные кабинеты и отправлять формы. Коннектор подключён, инструменты загружены.

## Для чего
- Извлечение текста и данных со страниц, которые плохо читаются обычным загрузчиком.
- Веб-поиск с извлечением содержимого.
- Мониторинг изменений на сайте и сбор таблиц (наборов данных) по однотипным объектам.
- Автоматизация действий на сайтах, включая вход в кабинет и отправку форм.

## Возможности
По списку инструментов сессии (около 38):
- **Разовые запросы:** `search`, `fetch_content`, `run_web_automation`, `run_web_automation_async` (фоновый запуск по явной просьбе).
- **Браузерные сессии:** `create_browser_session`, `list_browser_sessions`, `close_browser_session`.
- **Наборы данных:** `create_dataset`, `plan_dataset`, `populate_dataset`, `list_datasets`, `get_dataset`, `get_dataset_rows`, `delete_dataset`.
- **Мониторы:** `create_monitor`, `run_monitor`, `list_monitors`, `get_monitor`, `update_monitor`, `pause_monitor`, `resume_monitor`, `cancel_monitor`.
- **Глубокие исследования:** `start_deep_research`, `get_deep_research`, `list_deep_research`, `cancel_deep_research`.
- **Запуски и кошелёк:** `list_runs`, `get_run`, `wait_for_run`, `cancel_run`, `batch_status`, `batch_cancel`, `get_wallet`, `top_up_wallet`, `get_search_usage`, `list_fetch_usage`, `guide_next_step`.

## Чем выделяется
- Мнение: объединены несколько функций в одном сервисе: браузер, поиск, мониторинг и наборы данных. Для исследовательских задач это удобнее, чем три отдельных инструмента.
- Инструкции сервера заявляют ограничение: до 2 одновременных запусков автоматизации в этом аккаунте.

## Ограничения и риски
- **Класс C.** Вход в личные кабинеты и отправка форм меняют состояние сайтов и используют учётные данные. Перед запуском нужно подтверждение владельца, а учётные данные нельзя передавать в диалог.
- **Оплата.** Есть кошелёк и пополнение (`top_up_wallet`). Наборы данных тарифицируются за строки, их нужно запускать только по явной просьбе.
- Инструкции сервера называют наборы данных медленными и платными. Их не запускать для одиночных фактов.
- Условия сайтов, с которых извлекаются данные, могут запрещать автоматизированный доступ. Перед массовым сбором проверить правила.
- Хостинг данных и политика хранения не указаны в источниках сессии.

## Когда не подходит
- Сбор персональных данных людей без правового основания.
- Обход ограничений доступа сайтов и CAPTCHA.
- Задачи, которые проще решить по открытому API сайта.
