# TinyFish

## Суть

Коннектор TinyFish в инвентаре относится к группе «облачные браузеры» [1]. Инструкции MCP-сервера описывают его как инструменты для веб-поиска по запросу пользователя, извлечения содержимого страниц, исследований, мониторинга и автоматизации браузера [3]. В сессии 2026-11-10 коннектор подключён [1].

## Для чего

- Автоматизация сайтов: вход в порталы, отправка форм, сбор данных и отслеживание изменений, по описанию каталога [1].
- Веб-поиск и извлечение содержимого страниц [2][3].
- Мониторинг сайтов и наборы данных по однотипным объектам [2][3].
нет данных: целевая аудитория и типовые задачи пользователей в выдержке не описаны.

## Возможности

- В сессии загружено 38 инструментов с префиксом mcp__TinyFish__ [2].
- Автоматизация браузера: `create_browser_session`, `run_web_automation`, `run_web_automation_async` [2].
- Фоновый запуск `run_web_automation_async` — по явной просьбе пользователя о фоновом выполнении [3].
- Поиск и извлечение: `search`, `fetch_content` [2].
- Исследования и мониторинг: `start_deep_research`, `create_monitor`, `run_monitor` [2].
- Наборы данных: `create_dataset`, `populate_dataset`, `get_dataset_rows` [2]; создавать их стоит только по просьбе пользователя о таблице или списке однотипных объектов [3].
- Баланс: `get_wallet`, `top_up_wallet` [2].
нет данных: прочие лимиты и тарифы в выдержках не указаны [2][3].

## Чем выделяется

- Мнение: в одном коннекторе собраны браузер, поиск, мониторинг и наборы данных; для исследовательских задач это удобнее, чем отдельные инструменты [2][3].
- Мнение: инструкция сервера прямо предупреждает о медленных и тарифицируемых по строкам наборах данных, поэтому их стоит запускать редко [3].

## Ограничения и риски

- Удалённая точка подключения: hosted: true выведено по облачному браузерному агенту [1] и MCP-серверу [3].
- Вызов автоматизации может завершиться по таймауту, но запуск продолжит работу; статус стоит проверить до повтора [3].
- Наборы данных медленные и тарифицируются по строкам, их не создают ради одного факта [3].
- В аккаунте веб-автоматизация включена до двух одновременных запусков [3].
- Класс данных C выведен по описанию каталога: коннектор заходит в порталы и отправляет формы [1].
- По описанию каталога коннектор работает с сайтами и порталами; файлы на компьютере пользователя в описании не упомянуты [1].
- Оплата: есть кошелёк и пополнение баланса [2]; наборы данных тарифицируются по строкам [3].
нет данных: способ подключения, место обработки данных, срок хранения и способ хранения учётных данных входа в выдержках не указаны.

## Когда не подходит

- Мнение: для одного факта датасет не нужен; инструкция сервера прямо советует не создавать его ради единичного значения [3].
- Мнение: если нельзя передавать учётные данные входа облачному браузерному агенту, коннектор не подходит [1].
