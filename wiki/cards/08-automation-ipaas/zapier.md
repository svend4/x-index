# Zapier (две записи каталога)

## Суть
Zapier — платформа автоматизации между приложениями. В каталоге сессии найдено две записи с одним именем. Первая записана без описания и имеет состояние «не подключён». Вторая описана как «автоматизация рабочих процессов в тысячах приложений через диалог» и имеет состояние «отключён». Инструменты коннектора в сессии не загружены, поэтому возможности ниже описаны по каталогу и требуют проверки после подключения.

## Для чего
- Запуск существующих Zaps из диалога и создание простых автоматизаций.
- Перенос простых процессов между почтой, таблицами, CRM и мессенджерами без программирования.

## Возможности
- По описанию второй записи: доступ к «тысячам приложений» через диалог. Конкретный список инструментов не проверен, потому что коннектор не подключён.

## Чем выделяется
- Мнение: широкий каталог готовых интеграций. Чтобы сравнить с [[make-com]], нужна проба на одинаковых задачах. Описание «тысячи приложений» — заявление поставщика, не факт.

## Ограничения и риски
- Две записи в каталоге с одним именем: непонятно, какая из них официальная. Перед подключением сверить адрес и издателя.
- Коннектор класса C: запуск действий в подключённых приложениях меняет данные у владельца.
- Хостинг данных не указан в источниках сессии.

## Когда не подходит
- Если главное требование — хранение сценариев в Git или работа без внешнего сервиса.
- Если данные подопечных или клиентов нельзя передавать сервису без договора обработки.

## Альтернативы
- [[make-com]] — уже подключён в сессии, сравнение возможно сразу.
- [[ifttt]] — проще, потребительский уровень.
- [[workflow-automation]] — оркестрация внутри Claude.
