# chat-migration-assistant

## Суть
Скилл для переноса долгой работы между чатами; по описанию создаёт checkpoint-файлы, методологии, индексы и пошаговые инструкции [1][2].
По описанию применяется, когда чат приближается к лимиту контекста или пользователь хочет продолжить работу в новом чате [2].
В сессии скилл включён [1].

## Для чего
- По описанию: продолжение долгих проектов, которые требуют нескольких чатов, и перенос работы в новый чат без потери контекста (заявляет автор) [2].
- Адресат по описанию: пользователь, у которого большой проект требует нескольких чатов [2].
- нет данных о командах, ролях и сценариях сверх этого описания.
- Группа инвентаря: handoff и чекпоинты [1].

## Возможности
- Создание checkpoint-файлов, методологий, индексов и пошаговых инструкций [2].
- Быстрая оценка в несколько вопросов: проект, прогресс, задача следующего чата и стандарты [2].
- Обязательный пакет checkpoint: минимум четыре файла [2].
- Файл MASTER_INDEX.md для навигации по прогрессу и файлам по чатам [2].
- нет данных о полном составе пакета: в выдержке только начало скилла [2].

## Чем выделяется
- Мнение: скилл сосредоточен на моменте переноса между чатами, а не на долгосрочном хранении знаний; это мнение по описанию [2].

## Ограничения и риски
- По описанию срабатывает обычно около 180–190 тысяч использованных токенов из 200 тысяч [2].
- Создаются файлы checkpoint; где они сохраняются и уходят ли за пределы сессии, в выдержке не указано [2].
- нет данных об оценке качества переноса.
- нет данных о цене, модели оплаты, способе подключения, месте обработки данных и классе данных.

## Когда не подходит
- Мнение: если проект укладывается в один чат, перенос не нужен.
- Мнение: описание скилла [2] не упоминает импорт памяти; см. карточку [[import-memory]].
