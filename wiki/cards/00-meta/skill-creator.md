# skill-creator

## Суть
Скилл для создания новых skills, изменения и улучшения существующих и измерения их работы [1][2].
Процесс идёт по кругу: черновик, тестовые запросы, оценка результатов, переписывание и повтор [2].
Заявлена также оптимизация описания skill для точности срабатывания [2].

## Для чего
- Создание skill с нуля и правка существующего [2].
- Запуск оценок (evals) и бенчмарк работы с анализом разброса результатов [2].
- Оптимизация описания skill, чтобы он точнее срабатывал [2].
- Рассчитан на пользователей с разным уровнем знакомства с техническими терминами: язык общения подбирается по контексту [2].

## Возможности
- Черновик skill и его переписывание по обратной связи и результатам оценок [2].
- Тестовые запросы и количественные оценки; если их нет, они составляются [2].
- Показ результатов пользователю через скрипт generate_review.py [2].
- Отдельный скрипт улучшения описания (description improver) для оптимизации срабатывания [2].
- Повтор цикла и расширение набора тестов для проверки в большем масштабе [2].
- Работа без прогонов оценок, если пользователь этого не хочет [2].
- нет данных о структуре файлов skill и формате отчётов в выдержке.

## Чем выделяется
- Мнение: цикл из черновика, тестов, оценки и переписывания переводит создание skill от ощущений к проверяемому процессу.
- Мнение: отдельная оптимизация описания нужна, потому что описание влияет на точность срабатывания [2].

## Ограничения и риски
- Оценки требуют запусков тестовых запросов [2].
- Цикл повторяется до удовлетворённости пользователя: конец цикла определяет пользователь [2].
- нет данных о стоимости и времени оценок, лимитах и хранении результатов.

## Когда не подходит
- Мнение: если нужен подбор готовых инструментов, а не новый skill, подходит [[ecosystem-curator]].
- Мнение: для быстрой правки без оценок полный цикл избыточен; по выдержке его можно пропустить [2].
- Мнение: если нужна система из нескольких skills с лимитом описания, подходит [[multi-skill-system-builder]].

## Альтернативы
- [[ecosystem-curator]] — подбор и решения по готовым skills, коннекторам и плагинам.
- [[multi-skill-system-builder]] — архитектура системы из нескольких skills.
- [[mcp-builder]] — если нужен MCP-сервер, а не skill.
