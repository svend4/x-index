# multi-skill-system-builder

## Суть
Мета-скилл для создания больших систем из нескольких skills и доменных оркестраторов [1][2].
Он предлагает разбить сложный skill на два-три связанных по схеме Core/Extended/Companion, когда описание упирается в лимит 1024 знака [2].
В описании заявлены архитектурные шаблоны, методика разбиения, шаблоны для разных доменов и тестирование [2].

## Для чего
- Разбиение большого skill на несколько, если описание одного skill превышает лимит 1024 знака [2].
- Создание доменных менеджеров и оркестраторов, наборов профессиональных skills, отраслевых skills и сложных оркестраторов процессов [2].
- нет данных о том, для кого предназначен скилл, сверх перечисленных сценариев.

## Возможности
- Шаблон Dual-Skill (Core + Extended): в Core оркестрация, автоактивация, выполнение процессов и координация skills; в Extended подробная документация, примеры, лучшие практики и устранение неполадок [2].
- Признаки, когда делить: описание больше 1024 символов, много документации и примеров, основная функциональность отделяется от обучающих материалов [2].
- Выходные данные: структуры skills, YAML-шаблоны, логика координации и инструкции по установке [2].
- Шаблоны для разных доменов (юридический, социальный, бизнес, ресторанный, здравоохранение, образование и др.), стратегии оптимизации описания и фреймворки тестирования заявлены в описании [2].
- нет данных о содержании шаблонов отдельных доменов: в выдержке они только перечислены.

## Чем выделяется
- Мнение: разбиение по лимиту описания превращает ограничение длины в архитектурное решение: автоактивация остаётся в Core, подробности уходят в Extended.
- Мнение: шаблоны по доменам полезны, когда нужна единая структура для нескольких skills одной предметной области.

## Ограничения и риски
- Описание одного skill ограничено 1024 знаками; скилл применяется, когда описание превышает 1024 символа или нужна сложная архитектура [2].
- В выдержке подробно описан только шаблон Dual-Skill (Core + Extended); схема Companion упомянута в описании, но не раскрыта [2].
- Версия v1.0 указана в описании; нет данных о поддержке и истории изменений [2].
- нет данных о цене, хостинге и условиях использования.

## Когда не подходит
- Мнение: если skill укладывается в лимит описания и не имеет большого объёма документации, разбивать его не нужно [2].
- Мнение: для одного нового skill без сложной архитектуры достаточно [[skill-creator]].

## Альтернативы
- [[skill-creator]] — создание и улучшение одного skill.
- [[ecosystem-curator]] — инвентаризация и решения по уже установленным skills, коннекторам и плагинам.
