# nonprofit-grant-operations

## Суть
- По описанию в манифесте плагин управляет жизненным циклом грантов некоммерческих организаций: приём и отбор возможностей, заявки, награды, отчётность, продления и закрытие [2].
- В составе плагина один скилл grant-operations: операции с грантами некоммерческих организаций [1].
- Версия плагина 1.1.0 по манифесту [2]; плагин включён в сессии [1].

## Для чего
- Заявляет поставщик: приём и квалификация возможностей, работа с заявками [2].
- Заявляет поставщик: учёт присуждённых грантов, отчётность и продления [2].
- Заявляет поставщик: закрытие гранта [2].
- Для кого: для некоммерческих организаций, которые ведут гранты [1][2].

## Возможности
- Скилл grant-operations для операций с грантами некоммерческих организаций [1].
- Заявляет поставщик: охват полного цикла гранта (приём возможностей, квалификация, заявки, награды, отчётность, продления и закрытие) [2].
- нет данных о командах и действиях скилла: его инструкция в выдержках не приведена.

## Чем выделяется
- Мнение: охват всего цикла гранта в одном плагине отличает его от отдельных шаблонов заявок [2].
- Мнение: узкая направленность на некоммерческие организации делает плагин неочевидным выбором для коммерческих задач [1][2].

## Ограничения и риски
- Версия 1.1.0 по манифесту; зрелость и поддержку по выдержкам оценить нельзя [2].
- Лицензия MIT по манифесту [2].
- нет данных о классе данных: выдержки не описывают, какие данные плагин хранит и куда передаёт.
- нет данных о цене, способе подключения и месте обработки данных.

## Когда не подходит
- Мнение: если нужен только один шаблон заявки без учёта всего цикла гранта, плагин избыточен [2].
- Мнение: для коммерческих закупок и продаж, не связанных с грантами некоммерческих организаций, плагин не подходит [1][2].
