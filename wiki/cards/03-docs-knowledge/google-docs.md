# Google Docs (коннектор)

## Суть
Коннектор Google Docs подключён в сессии; в списке инструментов сессии два инструмента: `read_doc` и `update_doc` [2].
Состояние в инвентаре — `connected`, поставщик — Google [1].
Поставщик заявляет редактирование, комментирование и сводки документов [1].

## Для чего
- Чтение документа Google Docs через `read_doc` [2].
- Изменение документа через `update_doc` [2].
- Редактирование, комментирование и сводки документов, как заявляет поставщик [1].

## Возможности
- В сессии загружено два инструмента: `read_doc` и `update_doc` [2].
- Инструментов комментирования в списке сессии нет, поэтому заявленное комментирование в выдержках не подтверждено [2].
- Сервер описан в системных инструкциях как MCP-сервер, который предоставляет инструменты для работы с Google Docs [3].

## Чем выделяется
- Мнение: если документ уже лежит в Google Docs, правки можно вносить через `update_doc` в тот же документ, без создания копии.
- Мнение: для сложных правок (позиции, таблицы, стили) коннектора из двух инструментов может не хватить; см. [[google-workspace]].

## Ограничения и риски
- По названию инструмент `update_doc` меняет содержимое документа; ограничения и подтверждения в выдержках не описаны [2].
- Состояние `connected` не говорит, какие права выданы и как проходит авторизация [1].
- Класс данных C: инструмент `update_doc` меняет данные владельца [2].
- нет данных о цене, способе авторизации и месте обработки данных.
- Описание на английском; языки интерфейса в выдержках не указаны [1].

## Когда не подходит
- Мнение: если нужна работа с файлами Google Drive (поиск, создание, экспорт), этот коннектор не подходит: в выдержке только документы.
- Мнение: для правок с точным форматированием стоит проверить поведение `update_doc` на тестовом документе до работы с важным файлом.

## Альтернативы

- [[docs]] — документы, которые создаёт Claude; экспорт в Google Docs описан в карточке docs.
