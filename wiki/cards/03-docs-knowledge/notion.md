# Notion (коннектор)

## Суть
Коннектор Notion заявлен для поиска, обновления и запуска рабочих процессов между инструментами после подключения рабочего пространства Notion [1].
В сессии загружено 77 инструментов с префиксом notion- [2].
Состояние в инвентаре — `connected` [1]. Notion, по системным инструкциям, — место для документов, заметок, wiki и проектов [3].

## Для чего
- Страницы для работы, к которой пользователь будет возвращаться или которой будет делиться; базы данных для повторяющихся записей с общими полями [3].
- Поиск, чтение и обновление страниц, баз данных и комментариев [2].
- Работа с календарём Notion (инструменты с префиксом notion-calendar-) и заметками о встречах: `notion-query-meeting-notes` [2].
- нет данных о целевой аудитории коннектора.

## Возможности
- Поиск и чтение: `notion-search`, `notion-fetch`, `notion-list-recent-pages` [2].
- Создание и изменение: `notion-create-pages`, `notion-update-page`, `notion-create-database`, `notion-update-data-source` [2].
- Удаление и восстановление страниц: `notion-delete-pages`, `notion-restore-pages` [2].
- Память: `notion-memory-search`; Notion Memory хранит контекст о пользователе между разговорами и клиентами [2][3].
- Работа с сессиями: `notion-spawn-session`, `notion-send-message-to-session`, `notion-wait-session` [2].
- нет данных о лимитах API и параметрах инструментов.

## Чем выделяется
- Мнение: системные инструкции отделяют страницы для повторной работы от разовых ответов в чате; это помогает выбрать место для записи [3].
- Мнение: широкий набор инструментов в одном коннекторе удобен, если команда уже работает в Notion; без этого выгоды меньше.

## Ограничения и риски
- Коннектор подключён, поэтому инструменты могут менять страницы и базы, включая удаление страниц (`notion-delete-pages`) [2].
- Класс данных C: инструменты создают, меняют и удаляют страницы и базы владельца [2].
- Notion Memory хранит контекст о пользователе; что именно сохраняется и где, в выдержке не описано [3].
- нет данных о цене, способе авторизации и месте обработки данных.
- Описание на английском; языки интерфейса в выдержках не указаны [1].

## Когда не подходит
- Мнение: для разовых ответов, которые не нужно хранить, Notion не нужен; системные инструкции советуют оставлять их в чате [3].
- Мнение: если данные нельзя передавать в память Notion или в поиск по рабочему пространству, коннектор не подходит без проверки прав.
