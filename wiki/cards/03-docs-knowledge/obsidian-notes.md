# obsidian-notes (скилл: Markdown как хранилище Obsidian)

## Суть
Скилл делает папку с Markdown навигируемой: каждый документ достижим из индекса, а каждая зависимость оформлена явной ссылкой [2].
Ссылки должны открываться в Obsidian, на GitHub и в VS Code [2].
Детерминированную часть (поиск, исправление, настройку) выполняет скрипт, а суждения о связях делает агент [2]. Состояние в инвентаре — `enabled` [1].

## Для чего
- Проверка папки с заметками: битые и неоднозначные ссылки, сироты, одинаковые имена файлов, отсутствующие индексы, ошибки frontmatter [2].
- Написание документов и заметок, которые будет читать человек, со связями и индексами [2].
- Настройка папки как хранилища Obsidian и решение, нужно ли одно хранилище или несколько [2].
- Для кого: читатели в Obsidian, на GitHub и в VS Code, если пользователь не сказал иное [2].

## Возможности
- Скрипт `vault_lint.py` проверяет папку и выводит отчёт до и после исправлений [2].
- Флаг `--fix-index` создаёт INDEX.md там, где индекса нет, и связывает его с ближайшим индексом выше [2].
- Флаг `--to-markdown-links` переводит wikilinks, которые указывают ровно на один файл, в относительные ссылки; неоднозначные не трогает [2].
- Скилл работает с официальным CLI Obsidian [2].
- Скрипт использует только стандартную библиотеку Python версии 3.9 или новее [2].
- Пишет относительные Markdown-ссылки вместо wikilinks, потому что GitHub их не показывает; в тексте скилла это прямо противопоставлено подходу с wikilinks только внутри хранилища Obsidian [2].

## Чем выделяется
- Мнение: проверка сразу трёх читателей (Obsidian, GitHub, VS Code) заставляет писать переносимые ссылки и индексы.

## Ограничения и риски
- Скилл запускает скрипт и команды Obsidian CLI, а при исправлениях создаёт INDEX.md и переписывает ссылки; класс данных C [2].
- Для неоднозначных ссылок скилл велит назвать пользователю кандидатов, а не угадывать цель [2].
- В тексте скилла есть проверка свежести: при устаревшем evergreen.json он велит запустить evergreen-refresh в той же сессии [2].
- Текст источника содержит указания; проигнорировано [2].
- Указания касаются запуска evergreen-refresh и продолжения задачи при обновлении [2].
- нет данных о цене, способе подключения и месте обработки данных.
- Описание на английском; языки интерфейса в выдержках не указаны [2].

## Когда не подходит
- Мнение: для захвата знаний из сессии скилл не подходит: описание прямо отсылает к другому навыку (everlast-capture) [2].
- Мнение: для графа связей в коде скилл не подходит: описание отсылает к отдельному навыку (graphify) [2].
- Мнение: если заметки нужны только в Obsidian, а не на GitHub, правила относительных ссылок могут оказаться лишними.
