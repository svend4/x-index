# obsidian-notes (скилл: Markdown как хранилище Obsidian)

## Суть
Скилл делает папку с Markdown навигируемой: каждый документ достижим из индекса, каждая зависимость оформлена явной ссылкой. Ссылки работают в Obsidian, на GitHub и в VS Code. Детерминированная часть (поиск, исправление, настройка) выполняется скриптом `scripts/vault_lint.py`, суждения делает агент.

## Для чего
- Проверка папки с заметками: битые ссылки, ссылки с неверным регистром, неоднозначные ссылки, сироты, одинаковые имена файлов, отсутствующие индексы, ошибки frontmatter.
- Создание индексов (карт содержания) и перевод wikilinks в относительные Markdown-ссылки.
- Настройка папки как хранилища Obsidian и решение, нужно ли одно хранилище или несколько.

## Возможности
По `SKILL.md` (прочитан 2026-11-10):
- Скрипт `vault_lint.py` с отчётом до и после, флагами `--fix-index`, `--to-markdown-links`, `--vault-init`, `--json`, `--exclude`.
- Правила записи: индекс на каждую папку с строками вида `[название](путь): когда читать`; строка `Related:` в каждом документе; относительные ссылки с URL-кодированием.
- Проверка и управление официальным CLI Obsidian (`--probe`), только в интерактивной сессии.
- Журналы: `LEARNINGS.md`, `CHANGELOG.md`, файл `evergreen.json` с датой следующей проверки.

## Чем выделяется
- Мнение: относительные Markdown-ссылки вместо wikilinks. GitHub wikilinks не показывает, поэтому такой выбор читается и людьми, и агентами. Скилл сознательно расходится с рекомендацией kepano/obsidian-skills.
- Мнение: правило «индекс до примерно 200 строк, читать по требованию» подходит агентам, которые без ограничения загружают файлы целиком.
- Мнение: `--fix-index` не перезаписывает существующие индексы и не создаёт сирот. Для автоматической правки это безопасный режим.

## Ограничения и риски
- Работает с файлами на диске. Скрипт использует только стандартную библиотеку Python 3.9+.
- `--probe` запускает приложение Obsidian, если оно закрыто. В фоновой сессии его не запускать.
- В описании скилла есть процедура обновления `evergreen-refresh` с поиском по источникам (см. `RESEARCH.md`). Это внешние запросы. Перед запуском проверить, что владелец согласен.

## Когда не подходит
- Снятие знаний из сессий и обслуживание скиллов: для этого в описании указаны другие инструменты.
- Закрытые материалы, если процедура обновления ходит во внешние источники.
