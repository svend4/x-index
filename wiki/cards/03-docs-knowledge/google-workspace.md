# google-workspace

## Суть
Скилл задаёт правила создания и изменения файлов Google Docs, Sheets, Slides и Drive; в состав входят вспомогательные скрипты [1][2].
По тексту скилла коннекторы Google — тонкие обёртки над API Google, почти без собственных инструкций [2].
Состояние в инвентаре — `enabled` [1].

## Для чего
- Создание и изменение файлов Google Docs, Sheets и Slides в Google Drive пользователя [2].
- Не используется для вопросов, где файл только читается, и для файлов Word, Excel, PowerPoint и PDF [2].
- Группа инвентаря: совместное редактирование документов [1].
- нет данных о целевой аудитории скилла, кроме перечисленных сценариев.

## Возможности
- Справочники по приложениям: `references/docs.md` для Google Docs, `references/sheets.md` для Google Sheets, `references/slides.md` для Google Slides [2].
- Google Drive создаёт файлы всех трёх типов, но не правит их после создания [2].
- Правка существующего файла идёт в тот же файл, без создания нового [2].
- Позиции в Google Docs задаются в UTF-16 и сдвигаются после каждой вставки [2].
- Инструменты записи в Sheets разбирают ввод как интерфейс таблиц, поэтому текст может стать числом или датой [2].
- Позиции в Slides задаются в EMU; Slides не уменьшает текст под размер фигуры [2].

## Чем выделяется
- Мнение: разбивка по приложениям, с отдельным справочником на каждое, снижает риск правок не в том месте.

## Ограничения и риски
- Часть правил получена через коннекторы, а несколько не проверены; в описании это сказано прямо [2].
- Если нужного коннектора-редактора нет, изменение существующего файла останавливается и скилл велит спросить пользователя; новый файл создаётся через Drive [2].
- Класс данных C: скилл касается изменения файлов в Google Drive пользователя, то есть данных владельца [2].
- Текст источника содержит указания; проигнорировано: читать справочник перед правкой и проверять подключённые коннекторы [2].
- нет данных о цене, способе подключения и месте обработки данных.
- Описание на английском; языки интерфейса в выдержках не указаны [2].

## Когда не подходит
- Если документ, таблица или презентация запрошены без упоминания Google, скилл не применяется: используется собственный формат результата [2].
- Мнение: для вопросов о файлах Google без изменений скилл не нужен, достаточно чтения через коннектор.
