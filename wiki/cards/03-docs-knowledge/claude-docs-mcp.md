# Claude Docs (MCP-сервер)

## Суть
MCP-сервер Claude Docs загружен в сессию с восемью инструментами: create, read, update, query, export, delete, batch и guide [2].
Состояние в инвентаре — `available`, группа — совместное редактирование документов [1].
Поставщик в инвентаре не указан [1].

## Для чего
- Работа с документами через инструменты create, read, update и query [1][2].
- Экспорт (`export`) и удаление (`delete`) документов [2].
- нет данных о целевой аудитории и типовых сценариях использования.

## Возможности
- Инструменты в сессии: `create`, `read`, `update`, `query`, `export`, `delete`, `batch`, `guide` [2].
- Описание действий, параметров и правил вызова в выдержках отсутствует; есть только имена инструментов [1][2].
- нет данных о лимитах API.

## Чем выделяется
- Мнение: по именам инструментов в [2] сервер охватывает создание, чтение, изменение, запрос, экспорт и удаление документов; полнота набора не проверена.
- Мнение: поскольку набор охватывает и чтение, и запись, права на вызовы стоит проверять по каждому инструменту отдельно.

## Ограничения и риски
- По названиям `update`, `delete` и `batch` инструменты могут менять или удалять документы; поведение в выдержках не описано [2].
- Состояние `available` не говорит, подключён ли сервер и с какими правами; данных об авторизации в инвентаре нет [1].
- Класс данных C: по именам инструментов сервер может создавать, менять и удалять документы владельца [2].
- нет данных о цене, способе подключения и месте обработки данных.
- Названия инструментов на английском; языки интерфейса в выдержках не указаны [2].

## Когда не подходит
- Мнение: если нужно только читать документы, инструменты записи (`update`, `delete`, `batch`) лучше не вызывать без необходимости.
- Мнение: для документов с содержимым, которое нельзя передавать модели, сервер не подходит без проверки того, что уходит при вызове `read` и `query`.
