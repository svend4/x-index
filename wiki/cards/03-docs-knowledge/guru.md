# Guru

## Суть
Сервер Guru в инвентаре сессии относится к группе поиска по внутренним знаниям [1].
В сессии сервер требует авторизации, прежде чем его инструменты можно будет использовать [2].
Состояние в инвентаре — `auth_required` [1].

## Для чего
- Задачи инструмента в выдержках не описаны; в инвентаре указана только группа поиска по внутренним знаниям [1].
- нет данных о том, для кого предназначен сервер.

## Возможности
- Инструменты сервера доступны только после авторизации; их список в выдержках не приведён [2].
- нет данных о перечне инструментов, действиях и лимитах API.

## Чем выделяется
- Мнение: по имени записи сервер входит в плагин enterprise-search [1], поэтому, вероятно, относится к тому же поиску; это предположение, а не подтверждённая функция.
- Мнение: пока описание платформы пустое [1], сравнить Guru с другими источниками знаний по существу нельзя.

## Ограничения и риски
- Инструменты сервера можно использовать только после авторизации; это следует из уведомления о статусе сервера [2].
- Описание платформы в инвентаре пустое, поэтому объём данных, которые могут уйти наружу, не известен [1].
- нет данных о цене, способе авторизации, правах доступа и месте обработки данных.

## Когда не подходит
- Мнение: если нужен поиск по знаниям без авторизации в сервисе, карточка не подходит, пока сервер требует авторизации [2].
- Мнение: решение о подключении лучше принимать по данным поставщика, а не по этой карточке, пока описание пустое [1].

## Альтернативы
- [[enterprise-search]] — плагин, который в инвентаре указан в имени записи сервера Guru [1]; функции см. в карточке enterprise-search.
- [[notion]] — другой инструмент для знаний компании; функции см. в карточке notion.
