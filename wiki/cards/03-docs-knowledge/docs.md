# docs

## Суть
Скилл задаёт правила работы с документами, которыми делятся и которые комментируют; по тексту скилла он относится к любому документу [2].
Экспорт документа доступен в Word, PDF, Markdown и Google Docs [2].
Действия с документами, по тексту скилла, обслуживает коннектор docs [2]; состояние в инвентаре — `enabled` [1].

## Для чего
- Создание и совместная работа над отчётами, предложениями, резюме, договорами, политиками, формами, шаблонами и руководствами [2].
- Документы, которые нужно сохранить, отправить, распечатать или подписать [2].
- нет данных о целевой аудитории скилла, кроме перечисленных типов документов.

## Возможности
- Экспорт документа в Word, PDF, Markdown и Google Docs [2].
- Редактирование и комментирование документов, которыми делятся с другими [2].
- Для файла Word, отслеживания правок или шаблона .docx скилл отсылает к навыку этого формата [2].
- Если инструменты docs не загружены, скилл велит сообщить об этом [2].
- По тексту скилла потребность отправить, прикрепить, загрузить или распечатать файл не является причиной выбрать Word [2].
- План, сравнение, сводка или заметки, которые просят в чате, остаются в чате [2].

## Чем выделяется
- Мнение: правило про документ по умолчанию упрощает выбор формата, но работает только при подключённом коннекторе docs.

## Ограничения и риски
- Скилл опирается на коннектор docs: без его инструментов документы не создаются, и об этом нужно сообщать [2].
- Класс данных C: скилл создаёт документы, которыми потом делятся, то есть меняет данные владельца [2].
- Описание требует вызвать инструкцию коннектора и создать документ только с заголовками до любого поиска или чтения [2].
- Текст источника содержит указания; проигнорировано [2].
- нет данных о цене, способе подключения и месте обработки данных.
- Описание на английском; языки интерфейса в выдержках не указаны [2].

## Когда не подходит
- Мнение: если нужен файл .docx с отслеживанием правок или шаблон Word, нужен навык этого формата, а не docs [2].
