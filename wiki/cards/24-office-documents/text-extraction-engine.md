# text-extraction-engine

## Суть
- Навык извлекает текст из документов разных форматов: PDF, Word, Excel, PowerPoint, RTF, изображений через OCR, HTML, ePub и Markdown [1][2].
- Поддерживает пакетную обработку нескольких файлов и сохранение структуры документа [2].
- Навык включён в сессии [1].

## Для чего
- Извлечение текста из PDF для анализа [2].
- OCR сканов, изображений, снимков экрана и фотографий текста [2].
- Извлечение данных из офисных документов, например из Excel [2].
- Преобразование документов в обычный текст и очистка текста веб-страниц [2].
- Для кого: для пользователей, которым нужен текст из файлов для дальнейшей работы [2].

## Возможности
- Документы: PDF (в том числе сканы), Word, Excel, PowerPoint, RTF, ODT, ODS и ODP [2].
- Изображения: PNG, JPEG, GIF, BMP, TIFF, снимки экрана и сканы через OCR [2].
- Веб и книги: HTML с очисткой до текста, EPUB и Markdown [2].
- Прочее: текстовые файлы с определением кодировки, CSV, JSON и XML в текст [2].
- Пакетная обработка нескольких файлов и извлечение структурированных данных из документов [2].

## Чем выделяется
- Мнение: один навык покрывает офисные форматы, веб-страницы и OCR изображений, поэтому не нужен отдельный инструмент под каждый формат [2].
- Мнение: охват сканов и фотографий текста расширяет круг документов, пригодных для анализа [2].

## Ограничения и риски
- Класс данных не определён: выдержка описывает извлечение и использование текста в сессии, передача содержимого наружу в ней не описана [2].
- нет данных о точности OCR по сканам и фотографиям.
- нет данных о цене, способе подключения и месте обработки данных.

## Когда не подходит
- Мнение: если нужно изменить сам документ, а не получить из него текст, подходит другой навык: для PDF — [[pdf]], для Word — [[docx]].
- Мнение: для сканов низкого качества текст может быть извлечён неточно; точность в выдержках не описана.

## Альтернативы
- [[pdf]] — работа с PDF: текст, таблицы, формы, объединение и OCR.
- [[docx]] — создание и правка Word-документов.
- [[xlsx]] — таблицы .xlsx и .csv с формулами и форматированием.
