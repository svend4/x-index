# xlsx

## Суть
- Навык для таблиц .xlsx, .xlsm, .xltx, .csv и .tsv: чтение, создание, правка, очистка данных и преобразование форматов [1][2].
- Правка и создание выполняются через openpyxl, работа с большими объёмами данных через pandas [2].
- Навык включён в сессии [1].

## Для чего
- Редактирование существующей таблицы: столбцы, формулы, форматирование и графики [2].
- Создание таблицы с нуля или из других источников данных [2].
- Очистка неаккуратных табличных данных: некорректные строки, сдвинутые заголовки, мусорные данные [2].
- Для кого: для пользователей, для которых результатом является файл таблицы [2].
- Группа инвентаря: Word и Excel [1].

## Возможности
- Правка и создание таблиц с формулами и форматированием через openpyxl [2].
- Чтение и запись больших объёмов данных через pandas (read_excel, to_excel) [2].
- Быстрый просмотр листов через markitdown; координат ячеек в нём нет [2].
- Пересчёт формул скриптом recalc.py на базе LibreOffice; без пересчёта формулы читаются как пустые значения для инструментов, которые читают кэш значений [2].
- Требования к любому результату: шрифт Arial или Times New Roman, если пользователь не указал иное; отсутствие ошибок формул; формулы вместо готовых чисел; пометки допущений [2]. При правке существующего файла его соглашения имеют приоритет над этими требованиями [2].

## Чем выделяется
- Мнение: правило формул вместо готовых чисел позволяет таблице пересчитываться при изменении входных данных [2].
- Мнение: проверка ошибок формул до выдачи результата снижает риск передачи сломанной таблицы [2].

## Ограничения и риски
- Класс данных C: навык создаёт и правит таблицы, в том числе файлы владельца; при правке нужно сохранять их соглашения [2].
- Навык не применяется, если главный результат — Word-документ, HTML-отчёт, отдельный скрипт, конвейер данных или интеграция с Google Sheets API [2].
- Пересчёт выполняет LibreOffice; без него файл с формулами не получает значений [2].
- Для работы нужны openpyxl, pandas и markitdown; при отсутствии пакета его ставят через pip [2].
- нет данных о цене, способе подключения и месте обработки данных.

## Когда не подходит
- Мнение: если нужен только текст из таблицы без правки, достаточно извлечения текста: для этого есть навык text-extraction-engine.

## Альтернативы
- [[google-sheets]] — чтение и изменение таблиц Google Sheets через коннектор.
- [[docx]] — Word-документы, если результат должен быть текстом.
- [[text-extraction-engine]] — извлечение текста и данных из Excel и других форматов.
