# docx

## Суть
- Навык для создания, чтения, правки и преобразования Word-документов .docx и шаблонов .dotx [1][2].
- Новые документы создаются скриптом на библиотеке docx; существующие правятся через распаковку и правку XML; чтение выполняется через pandoc [2].
- Навык включён в сессии [1].

## Для чего
- Создание документов Word, поиск и замена текста, вставка и замена изображений, работа с отслеживанием изменений и комментариями [2].
- Превращение содержимого в оформленный документ Word [2].
- Для кого: для пользователей, которым нужен файл .docx или .dotx для скачивания, отправки или печати [2].
- Группа инвентаря: «Word и Excel» [1].

## Возможности
- Создание нового документа скриптом на docx (npm); библиотека предустановлена [2].
- Правка существующего файла: распаковка, правка word/document.xml и упаковка обратно, поскольку docx-js не открывает существующие файлы [2].
- Чтение содержимого через pandoc [2].
- Тонкости создания: размер страницы по умолчанию A4, двойные ширины таблиц, оформление заголовков и оглавления, списки через нумерацию [2].
- После записи .docx документ рендерится и проверяется визуально [2].
- Если сессия предлагает собственный инструмент документов и пользователь не назвал Word, навык советует создавать документ там [2].

## Чем выделяется
- Мнение: в навыке собраны типовые ошибки генерации Word-файлов, например размер страницы по умолчанию и заливка таблиц, что снижает число переделок [2].
- Мнение: правило выбора инструмента уменьшает число лишних файлов: если сессия предлагает собственный инструмент документов, а пользователь не назвал Word, не попросил отслеживать изменения и не передал .docx/.dotx, документ создаётся там [2].

## Ограничения и риски
- Класс данных C: навык создаёт и правит файлы .docx, в том числе документы владельца [2].
- Не подходит для PDF, таблиц, Google Docs и кода, не связанного с созданием документов [2].
- нет данных: куда уходит содержимое документов за пределы сессии.
- Создание требует библиотеки docx; если её нет, по инструкции её ставят через npm install docx [2].
- нет данных о цене, способе подключения и месте обработки данных.

## Когда не подходит
- Мнение: если пользователь не назвал формат, а сессия предлагает собственный инструмент документов, навык не нужен [2].
