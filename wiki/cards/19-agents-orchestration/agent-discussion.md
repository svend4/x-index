# agent-discussion

## Суть
- Плагин координирует дебаты нескольких агентов на разных ИИ-платформах по общему файловому протоколу; в описании названы Claude Code, Antigravity, Copilot, Gemini CLI и другие [2].
- В составе плагина один скилл agent-discussion [1].
- Каждый агент читает скилл и сам ведёт представление, очерёдность ходов и поиск консенсуса [2].

## Для чего
- Обсуждение одного вопроса несколькими агентами с итогом по консенсусу [2].
- Сопоставление позиций агентов разных платформ [2].
- Для тех, кто хочет провести дебаты между агентами без ручной координации [2].
- Группа инвентаря: дебаты и ревью агентов [1].

## Возможности
- Общий файловый протокол для обмена ходами между агентами [2].
- Автономная работа агентов: представление, очерёдность ходов и консенсус [2].
- Один скилл agent-discussion в составе плагина [1].

## Чем выделяется
- Заявлено автором: агенты действуют автономно, включая представление, очерёдность ходов и консенсус [2].
- Мнение: обмен через общий файл [2] может упростить подключение разных агентов; требуется ли общий API, в выдержках не указано.

## Ограничения и риски
- Класс C основан на обмене ходами через общий файл [2].
- Обмен идёт через общий файл [2]; где он лежит и кто имеет к нему доступ, в выдержках не указано: нет данных.
- Обсуждение идёт между агентами разных платформ [2]; какие данные при этом уходят за пределы владельца, в выдержках не указано: нет данных.
- Версия 0.1.0 [2].
- нет данных: цена, лимиты и лицензия в выдержках не указаны.

## Когда не подходит
- Мнение: если нужен один ответ или быстрое мнение, дебаты нескольких агентов избыточны.
- Мнение: для обсуждения материалов с персональными данными или коммерческой тайной, пока неизвестно, где лежит общий файл и кто им пользуется [2].
