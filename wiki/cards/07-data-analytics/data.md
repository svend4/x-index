# data

## Суть
- Плагин data включает 10 скиллов: анализ, дашборды, визуализация, SQL, статистика и валидация данных [1].
- По манифесту версия плагина 1.1.0, автор Anthropic [2].
- В сессии 2026-11-10 плагин включён [1].

## Для чего
- Написание SQL, исследование наборов данных и получение выводов [2].
- Построение визуализаций и дашбордов, превращение сырых данных в понятные истории для заинтересованных лиц [2].
- Группа записи инвентаря: дашборды и BI [1].

## Возможности
- Скиллы по категориям инвентаря: анализ, дашборды, визуализация, SQL, статистика, валидация данных [1].
- нет данных о именах скиллов и порядке их работы: в выдержках только категории [1][2].

## Чем выделяется
- Мнение: плагин покрывает путь от SQL до визуализации и дашборда в одном наборе [1][2].
- Мнение: описание нацелено на подачу выводов заинтересованным лицам, а не только на расчёты [2].

## Ограничения и риски
- Класс данных B: плагин работает с наборами данных владельца, поэтому их содержимое проходит через модель [2].
- Версия 1.1.0 по манифесту [2]; зрелость по выдержкам не оценена.
- нет данных о подключениях к хранилищам и источникам данных, цене, способе входа и месте обработки данных.

## Когда не подходит
- Мнение: если данные нельзя передавать модели, плагин не подходит из-за класса данных B [2].
- Мнение: для задач без SQL и данных плагин избыточен [1][2].

- [[xlsx]] — файлы .xlsx, .csv и .tsv, если данные лежат в таблицах.
