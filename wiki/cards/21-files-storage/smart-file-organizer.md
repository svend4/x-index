# smart-file-organizer

## Суть
- Навык упорядочивает файлы по смыслу их содержимого: создаёт папки и категории, сортирует фото по EXIF и событиям [1][2].
- Навык включён в сессии [1].

## Для чего
- Наведение порядка в беспорядочных папках, например в Downloads, и в коллекциях файлов [2].
- Сортировка файлов по содержимому, а не только по расширению [2].
- Создание папок, которые соответствуют содержимому, и группировка файлов по проекту [2].
- Очистка рабочего пространства с сотнями несортированных файлов [2].
- Для кого: для пользователей, которым нужна организация файлов сверх простого переименования [2].

## Возможности
- Читает содержимое документов PDF, DOCX и TXT, чтобы понять, что в них находится [2].
- Извлекает метаданные: EXIF фотографий, свойства документов и временные метки [2].
- Группирует файлы по смыслу, а не только по типу [2].
- Обрабатывает смешанные типы файлов в одной операции: фото, документы, код, архивы [2].
- Порядок работы: сканирует файлы, определяет тип, извлекает содержимое или метаданные, категоризирует, создаёт структуру папок и перемещает файлы после подтверждения [2].

## Чем выделяется
- Мнение: группировка по смыслу содержимого, а не по расширению, отличает навык от простых сортировщиков по типу файла.
- Мнение: перемещение только после подтверждения [2] снижает риск неожиданного смешения или потери файлов при массовой операции.

## Ограничения и риски
- Класс данных C: навык перемещает файлы владельца, но только после подтверждения [2].
- Навык читает содержимое документов (PDF, DOCX, TXT), а не только имена [2].
- нет данных о том, какое содержимое уходит за пределы сессии и где оно обрабатывается.
- нет данных о цене, способе подключения и ограничениях по объёму папок.

## Когда не подходит
- Мнение: для простого переименования файлов навык избыточен: описание относит к задачам организацию сверх простого переименования [2].
- Мнение: для конфиденциальных документов сначала стоит определить, какое содержимое навык будет читать [2].

- [[duplicate-hunter]] — поиск дубликатов файлов по хешу и похожих документов, если нужна только дедупликация.
- [[batch-file-renamer]] — пакетное переименование по шаблонам, если порядок задаётся именами файлов.
