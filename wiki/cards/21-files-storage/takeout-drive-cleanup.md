# takeout-drive-cleanup

## Суть
- Навык очищает Google Диск от повторов Google Takeout по MD5 без скачивания архивов; перенос в корзину возможен только с согласия владельца [1][2].
- Проект навыка написан на Google Apps Script: владелец принимает решения, Claude готовит проверки, сводки и журнал работы [2].
- Навык включён в сессии [1].

## Для чего
- Освобождение места на Диске, заполненном архивами Takeout и их копиями [2].
- Поиск копий, сохранение уникального и освобождение места без скачивания архивов целиком [2].
- Для кого: для владельца Google Диска, который работает с Claude в паре [2].

## Возможности
- Поиск копий по MD5 и разбор оглавлений ZIP-архивов [2].
- Сохранение уникального: этот шаг входит в процесс навыка [2].
- Перенос в корзину партиями: перед каждой партией запускается свежая проверка, сначала выводится сводка по партии, затем вопрос владельцу [2].
- Необязательный коннектор Google Диска для чтения отчётов и переноса в корзину одного файла [2].
- Журнал работы ведётся в документе владельца: Google Doc или другой документ [2].

## Чем выделяется
- Мнение: сочетание проверки по MD5, переноса партиями и явного согласия владельца снижает риск потери уникальных файлов [2].
- Мнение: поиск опирается на содержимое копий, а не на похожие имена, поскольку удаление по имени в правилах навыка не применяется [2].
- Мнение: навык не удаляет безвозвратно и не очищает корзину; это остаётся за владельцем [2].

## Ограничения и риски
- Класс данных C: навык переносит файлы владельца в корзину, но только после согласия на каждую партию [2].
- Корзина Google хранит файлы 30 дней по описанию навыка; очищает корзину владелец [2].
- Манифест проекта даёт чтение Диска, создание своих файлов и внешние запросы; область drive нужна только необязательному модулю переноса и только на время переноса [2].
- Для работы нужен код проекта: папка apps-script и docs; если кода в сессии нет, его нужно получить от владельца [2].
- Функции запускает владелец или Claude через браузер владельца в редакторе Apps Script [2].
- В правилах навыка для Claude: не отправлять имена, id и содержимое файлов никуда, кроме журнала владельца и Диска [2]. Код проекта в выдержках не проверен; манифест разрешает внешние запросы [2].
- нет данных о цене, способе подключения и месте обработки данных.

## Когда не подходит
- Мнение: если владелец не может подтверждать каждую партию, навык не подходит по своим правилам работы [2].
- Не применять для удаления файлов по имени: похожее имя ничего не доказывает [2].
- Не применять для общих дисков и чужих файлов: проект их не переносит [2].
- Не применять для пары файлов, которые проще убрать вручную [2].

## Альтернативы
- [[duplicate-hunter]] — поиск дубликатов по хешу, похожим документам и изображениям, сравнение метаданных; подходит, если не нужен проектный процесс для Takeout.
- [[google-drive]] — коннектор Google Drive для поиска, чтения, создания и изменения файлов; без проектного процесса очистки.
- [[smart-file-organizer]] — упорядочивание файлов по содержимому: папки, категории, сортировка фото по EXIF и событиям; подходит, если задача в порядке, а не в повторах.
