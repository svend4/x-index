# web-artifacts-builder

## Суть
- Набор инструментов для создания многокомпонентных HTML-артефактов claude.ai на современном фронтенде: React, Tailwind CSS и shadcn/ui [2].
- Скилл рассчитан на сложные артефакты с состоянием, маршрутизацией и компонентами shadcn/ui, а не на простые одиночные HTML- или JSX-файлы [2].
- В сессии 2026-11-10 скилл включён [1].

## Для чего
- Сложные артефакты, в которых нужны состояние, маршрутизация и компоненты shadcn/ui [2].
- Сборка проекта в один HTML-файл для показа пользователю [2].
- Группа инвентаря: IDE и агенты для кода [1].
- нет данных о целевой аудитории сверх описания.

## Возможности
- Инициализация проекта скриптом `scripts/init-artifact.sh`: React и TypeScript через Vite, Tailwind CSS 3.4.1, алиасы путей `@/` [2].
- В проекте заранее установлены более 40 компонентов shadcn/ui и зависимости Radix UI [2].
- Сборка всего кода в один HTML-файл скриптом `scripts/bundle-artifact.sh` [2].
- Стек: React 18, TypeScript, Vite, Parcel для сборки, Tailwind CSS и shadcn/ui [2].
- Необязательный шаг: тестирование артефакта [2].
- нет данных о сроках поддержки и обновлениях скилла.

## Чем выделяется
- Мнение: скилл задаёт стек и сборку в один файл, что упрощает перенос артефакта в claude.ai [2].
- Мнение: руководство прямо предупреждает против шаблонного оформления: чрезмерного центрирования, фиолетовых градиентов, одинаковых скруглений и шрифта Inter [2].

## Ограничения и риски
- Класс данных не оценён: в выдержке не описана передача содержимого проекта наружу [2].
- Руководство указывает совместимость с Node 18+; версию Vite скрипт определяет автоматически и фиксирует её [2].
- Инициализация и сборка выполняются скриптами из руководства [2].
- нет данных о цене, способе входа и месте обработки данных.

## Когда не подходит
- Простые одиночные HTML- или JSX-артефакты: руководство прямо указывает, что скилл для них не подходит [2].
- Мнение: если нельзя запускать скрипты инициализации и сборки, скилл не подойдёт [2].
