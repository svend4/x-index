# mcp-builder

## Суть
- Руководство по созданию MCP-серверов (Model Context Protocol), которые позволяют LLM работать с внешними сервисами через инструменты [2].
- Описывает разработку на Python с FastMCP и на TypeScript с MCP SDK [1][2].
- В сессии 2026-11-10 скилл включён [1].

## Для чего
- Проектирование и разработка MCP-серверов для интеграции внешних API или сервисов [2].
- Выбор между полным покрытием API и инструментами-сценариями (workflow tools) [2].
- нет данных о целевой аудитории сверх описания.

## Возможности
- Руководство описывает четыре фазы работы; первая из них — исследование и планирование [2].
- Рекомендации по именам инструментов с префиксами, например `github_create_issue` [2].
- Рекомендации по контексту: краткие описания инструментов, фильтрация и постраничный вывод результатов [2].
- Рекомендации по ошибкам: сообщения с конкретными подсказками и следующими шагами [2].
- нет данных о примерах кода, тестировании и версиях протокола: в выдержке их нет [2].

## Чем выделяется
- Мнение: руководство измеряет качество сервера тем, насколько он помогает LLM решать реальные задачи [2].
- Мнение: руководство советует учитывать разные клиенты, потому что их работа с инструментами различается [2].

## Ограничения и риски
- Класс данных A: руководство описывает разработку, в выдержке не описана передача данных владельца наружу [2].
- В выдержке только начало руководства; остальные фазы в ней не описаны [2].
- нет данных о цене, способе входа и месте обработки данных.

## Когда не подходит
- Мнение: если нужно подключить уже готовый MCP-сервер, а не писать свой, руководство не поможет [2].
- Мнение: для разовой интеграции без протокола MCP руководство избыточно [2].

## Альтернативы
- [[github-mcp]] — готовый MCP-сервер GitHub, если нужен доступ к репозиториям, а не собственный сервер.
- [[skill-creator]] — создание собственных скиллов, если нужен скилл, а не MCP-сервер.
