# Chat Migration Assistant

Помогает продолжать работу между чатами когда текущий чат приближается к лимиту контекста (обычно ~180,000-190,000 токенов использовано из 200,000).

## Когда использовать

**Триггеры:**
- Пользователь спрашивает про "новый чат", "переезд", "миграцию"
- Упоминает что "контекст заканчивается"
- Хочет "сохранить прогресс" для продолжения
- Работает над проектом требующим >1 чата
- Видишь system warning что токенов осталось <20,000

## Быстрая оценка (2 минуты)

Спроси пользователя:
1. **Проект:** Что продолжается? (1 предложение)
2. **Прогресс:** Что сделано в этом чате? (ключевые результаты)
3. **Scope следующего чата:** Что делать дальше?
4. **Есть ли стандарты?** (методология, style guide, качество)

## Создание Checkpoint Пакета

**1. MASTER_INDEX.md** — навигация
